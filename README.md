# Cyber Bomber — Telegram HTMLBubbles Game

Полноценная игра **Bomberman** в стиле Cyberpunk / Neon Arcade, оптимизированная специально под ограничения интерактивных сообщений Telegram 13.2 (**HTMLBubbles**):

- **Размер всего файла:** ~26 КБ (скрипт ~22 КБ), что строго укладывается в лимит **32 КБ**.
- **0 внешних сетевых запросов:** нет сторонних CDN, шрифтов, PNG/JPG текстур и MP3 файлов.
- **Процедурная графика:** Неоновый стиль, рендеринг на HTML5 Canvas (свечение, частицы взрывов, тряска экрана, плавающие очки).
- **Синтез звука Web Audio API:** 5 процедурных 8-битных звуковых эффектов (сброс бомбы, взрыв белым шумом, сбор бонусов, ликвидация дронов, телепортация через портал, кнопка Mute/Unmute).
- **Адаптивное управление:** 
  - 📱 Мобильный экранный D-Pad + кнопка 💣 (с защитой от случайного скролла баббла `touch-action: none`).
  - 💻 Клавиатура для Desktop/Web Telegram: `WASD` / Стрелки + `Пробел` / `Enter` / `E` для бомбы.
- **Геймплей:**
  - Кампания с растущей сложностью по секторам (Zone 1, 2, 3...).
  - Разные типы кибер-дронов (быстрые сталкеры и дроны, способные фазировать сквозь барьеры).
  - Сглаживание движения по углам блоков (*Corner sliding*), чтобы игрок не застревал в проходах.
  - Бонусы из разрушаемых энергоблоков: 💣 (+1 бомба), 🔥 (+радиус огня), ⚡ (+скорость).
  - Квантовый портал выхода активируется после зачистки сектора от всех дронов.
  - Сохранение рекорда (High Score) в памяти/хранилище.

## 🤖 Запуск Telegram-бота (`bot.py`)

В проект включён готовый скрипт на базе `aiogram 3.x` для отправки игры пользователям в Telegram.

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск бота:
```bash
export BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
python3 bot.py
```

### 3. Использование в Telegram:
- Отправьте боту команду `/start` или `/play`.
- Бот отправит файл `cyber_bomber.html`. В клиентах Telegram 13.2+ с поддержкой **HTMLBubbles** сообщение открывается прямо как интерактивная игра внутри чата.
- Также можно подключить URL (например, разместить `index.html` на GitHub Pages) и запускать игру через кнопку WebApp!
